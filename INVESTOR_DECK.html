ProductTwo layers, one closed loop

Off-chain · Scanner

  • Polls configured 2-leg cycles across venues
  • Quotes via each router's own getAmountsOut
  • Pricess the live Aave premium from FLASHLOAN_PREMIUM_TOTAL
  • Nets gas, applies slippage pins & profit floor
  • Static-simulates the full loan before any send
  • Dry-run by default; SEND=true to trade; webhook alerts

On-chain · Flash-loan engine

  • FlashLoan.sol — Aave V3 receiver, only registered strategies
  • DexRouteArbStrategy — trusted routers only
  • On-chain guards: minProfit, initiator checks, deadline, minAmountOut pins
  • Owner controls: pause, withdraw, per-router trust
  • Emits Requested / Executed / Withdrawn events → ledger

Borrow-asset sourcing solved without faucets: ETH is wrapped to WETH and the notional is flash-borrowed from Aave itself — the only capital required is gas.

Gate 5 proved itself

The pre-send simulation executed against the real Aave pool in both dry cycles — identical result each time (gross 73,688,138,478,710 wei). The simulated path and the settled path are the same code.

Gate 6 has on-chain teeth

Even if off-chain logic is wrong, the strategy reverts the whole flash loan unless out ≥ amount + premium + minProfit and both minAmountOut pins hold. A losing cycle cannot settle.

Gate 4 caught the one defect — now fixed

Gate 4 approved a cycle it should have refused (gas priced at 20 wei vs 2 gwei actually paid — finding F1). The flaw was measured, documented, and fixed within a day (gas-price floor + on-chain net guard + regression tests) — see unit economics.

Unit economics · honest viewGross profit was real. Net was not — here's exactly why.

The trade, per unit (wei)

Gross arb profit
+73.7 µETH Aave premium
−1.0 µETH Gas (actual, receipt)
−1,923.9 µETH Net
−1,850.2 µETH

Bars scaled to gas (the dominant term at this notional). Trading margin after premium was 98.6% — gas, not the arb, decided the outcome.

Finding F1 — a real defect, measured

  • Scanner priced gas from getFeeData() → 20 wei/gas (basefee ~16 wei at that instant).
  • Transaction actually broadcast at the configured 2 gwei pin — receipt confirms exactly 2.0 gwei.
  • Netting saw 26,128,860 wei instead of 1,923,896,000,000,000 wei → gate passed a money-losing cycle.

Fix — applied 2026-10-19, next day

gasPriceFloorWei → decision uses max(feeData, floor) — the same price the sender will pay — plus an on-chain net guard: the enforced minProfit now includes the gas budget, so a trade that can't cover its own gas reverts. With a 2 gwei floor this cycle is refused at Gate 4.

Cost of finding this: ~0.002 testnet ETH. The alternative — finding it on mainnet — does not bear thinking about. Fixed with regression tests (68 passing) and a forced-floor rerun that refuses the same trade, exit 0. A test suite whose job is to embarrass the product before capital does: working as intended.

  • eth_getLogs served by lagging nodes → bounded ledger retries with graceful degradation.
  • Interrupted runs resume — never re-deploy, never double-seed.

Failure discipline

  • 9 live attempts, each failure fixed at the root cause: RPC quirk, missing mint, balance guard, estimator semantics — no assertion was ever weakened.
  • Two self-inflicted code bugs caught by running the tool itself, not by luck.

Why the economics improve from here

  • Notional scales, gas doesn't: the ~962k-gas tx costs the same whether it trades 0.002 or 0.2 WETH. Our test pools were deliberately tiny (0.1 WETH); production pools are orders of magnitude deeper, so a larger notional turns fixed gas into a rounding error — with F1's fix, size becomes an input, not an accident.
  • Premium is the only capital cost: 5 bps, paid only on success.
  • Infra cost is a laptop + RPC: the hard engineering (guards, ledger, audit trail, resilience) is already built and tested.
  • Breadth compounds: every new venue/pair re-uses the same verified pipeline.
